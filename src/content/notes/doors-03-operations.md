> 账号：使用你自己的 DOORS 账号（需 Database Manager 权限）
> 用法：从上到下逐项完成，每项做完对照"检查点"确认，再进下一项。

## 任务 1：数据库导航

**目标**：熟悉库结构，学会用位置框直达。

**步骤**

1. 打开 DOORS，用你自己的 DOORS 账号登录。
2. 看左侧树 `DOORS Database`，展开后应有 8 个文件夹：`00 用户需求` ~ `07 代码单元`。
3. 点上方**位置**输入框，输入 `/03 软件需求`，回车。
4. 观察右侧列表只剩 `SW_平台软件需求` 一行。
5. 再输入 `/`，回车，回到根目录。

**预期结果**

- 位置框是全局最快的导航方式，支持完整路径。
- 列表会随路径实时变化。

**检查点**

- [ ] 能看到 8 个文件夹
- [ ] 输入 `/03 软件需求` 后列表只剩 1 个模块

> 提示：如果某个文件夹里看不到链接模块（如 `SYS_to_SUB`），点工具栏**过滤器**（漏斗图标），把"链接模块"类型勾上。

## 任务 2：打开并读懂一个模块

**目标**：认识模块窗口的三个区域。

**步骤**

1. 位置框输入 `/01 系统需求`，回车。
2. 双击 `SYS_系统需求规格`。
3. 观察窗口标题：`/01 系统需求 中的"SYS_系统需求规格"当前 0.0（正式 模块）`
4. 认三个区域：
   - **左侧大纲**：章节 + 需求，带缩进
   - **中间表格**：`ID` 列 + `SYS 需求规格说明` 列
   - **顶部工具栏**：`Standard view` 视图下拉、`所有级别` 级别下拉
5. 在左栏点章节前的 `−` 折叠，再点 `+` 展开。
6. 把级别下拉从 `所有级别` 改成 `仅显示级别 1`，观察需求行被隐藏。

**预期结果**

- 章节标题加粗，需求行编号形如 `SYS-0001`。
- 级别过滤只留章节骨架。

**检查点**

- [ ] 能折叠/展开章节
- [ ] 切到"仅显示级别 1"后只剩标题行

## 任务 3：查找与定位

**目标**：在大库里按业务编号或绝对编号定位。

**步骤**

1. 回到 `所有级别`。
2. 点一下表格区域（让焦点在表上）。
3. 按 `Ctrl+F`（或菜单 `编辑 → 查找...`），输入 `SYS-0042`，点"查找下一个"。
4. 按 `F3` 继续找下一个，`Shift+F3` 找上一个。
5. 再按 `Ctrl+G`（`编辑 → 转至...`），输入 `119`，回车。
6. 观察光标跳到第 119 号对象（就是 `SYS-0001`）。

**预期结果**

- `Ctrl+F` 按正文搜索；`Ctrl+G` 按绝对编号跳转。

**检查点**

- [ ] 能定位到 `SYS-0042`
- [ ] 能用 `119` 跳到 `SYS-0001`

> 区分：`SYS-0042` 是业务编号（在正文里），`119` 是 DOORS 绝对编号（最左列）。

## 任务 4：列与视图

**目标**：按角色裁剪表格，并保存成可复用视图。

**步骤**

1. 在模块窗口菜单 `插入 → 列...`。
2. 在属性列表里选 `最后修改时间`，确定。
3. 再执行一次 `插入 → 列...`，选 `最后修改者`，确定。
4. 点列头 `最后修改时间` 排序（点两次可切换升降序）。
5. 菜单 `查看 → 另存为...`，输入 `审计视图`，确定。
6. 点左上角视图下拉（现在是 `Standard view`），选 `审计视图`。

**预期结果**

- 表格多出两列，可按修改时间排序。
- 视图下拉里出现自定义视图。

**检查点**

- [ ] 多出"最后修改时间""最后修改者"两列
- [ ] 视图下拉能看到 `审计视图`

> 注意：`查看 → 表格属性...` 管的是**单元格字体**，不是列，别点错。
> 删列：点列头选中 → 按 `Delete`。

## 任务 5：追溯跳转（核心中的核心）

**目标**：从一条需求走到它的上下游。

**步骤**

1. 打开 `SYS_系统需求规格`。
2. 菜单 `查看 → 显示 → 勾选「链接箭头」`。
3. 看行尾右侧出现小三角：紫色 **▶** = 出链，橙色 **◀** = 入链。
4. **右键**点击 `SYS-0001` 行尾的紫色箭头。
5. 弹出目标模块列表：
   ```
   /02 子系统需求/ACS_通行子系统需求  >
   /02 子系统需求/NRG_能源子系统需求  >
   /02 子系统需求/SEC_安防子系统需求  >
   ```
6. 鼠标悬停 `SEC_安防子系统需求`，展开二级菜单，点 `SEC-0001`。
7. 观察：自动打开 `SEC_安防子系统需求` 并定位到该行（黄色高亮）。

**预期结果**

- 左键单击箭头只在状态栏显示路径提示，**不会跳转**。
- 双击箭头无反应。
- **右键才是导航入口**。

**检查点**

- [ ] 行尾看到 ▶ / ◀ 箭头
- [ ] 右键能弹出目标模块列表
- [ ] 点击目标后成功跳转并高亮

> 完整链：`UR-0001 → SYS-0001 → SEC-0001 → SW-0001`，另外 `SW-0001` 还有入链来自 `CODE-0001` 和 `TC-0001`。

## 任务 6：链接模块与矩阵视图

**目标**：看"关系"本身，而不是单条需求。

**步骤**

1. 位置框输入 `/01 系统需求`，回车。
2. 列表里应看到 `SYS_to_SUB`（类型 Link）。若没有，用**过滤器**放出链接模块。
3. 双击 `SYS_to_SUB`，窗口是空的（浅蓝底）。
4. 点顶部下拉框 `未选择任何链接集`，会出现 3 项：
   - `SYS_系统需求规格 -> ACS_通行子系统需求`
   - `SYS_系统需求规格 -> NRG_能源子系统需求`
   - `SYS_系统需求规格 -> SEC_安防子系统需求`
5. 选第一项，出现**矩阵视图**：
   - 左侧竖轴 = 源模块（SYS）
   - 顶部横轴 = 目标模块（ACS）
   - **蓝色方块** = 存在一条链接
6. 工具栏右侧可切换"列表视图"，每行一条链接。

**预期结果**

- 链接模块是"关系容器"，一个链接模块可装多对模块的链接集。
- 矩阵直观展示覆盖密度。

**检查点**

- [ ] 能看到 3 个链接集
- [ ] 矩阵里看到蓝色方块

## 任务 7：讨论（评审留痕）

**目标**：给需求挂评审意见。

**步骤**

1. 打开 `SYS_系统需求规格`，找到 `SYS-0082`（或任意一条）。
2. 右键该行 → 点 `新建对象讨论...`。
3. 填写：
   - 摘要：`SYS-0082 日志保留 180 天需确认合规`
   - 注释：`请安全组确认是否符合等保要求。`
4. 点 `保存`。
5. 查看：菜单 `讨论 → 查看对象讨论...`，切换到 `讨论` 页签。

**预期结果**

- 讨论**不会**在表格里显示图标，必须通过菜单查看。
- 列表显示摘要、创建者、上次修改时间。

**检查点**

- [ ] 保存成功（无报错）
- [ ] 讨论列表能看到刚添加的记录

## 任务 8：变更管理

**目标**：从变更单追溯到受影响需求。

**步骤**

1. 位置框输入 `/06 变更管理`，回车。
2. 双击 `CR_变更单`，看到 15 张变更单。
3. 打开任意一张，正文形如：
   `CR-001 支付接口超时调整【类型:接口｜影响:高｜状态:已批准｜关联需求:SYS-0012】`
4. 看该行行尾箭头，右键 → 选择关联的需求 → 跳转。

**预期结果**

- 变更单与需求通过链接模块 `CR_to_REQ` 关联。
- 改需求前先查变更单，改完再更新变更单状态。

**检查点**

- [ ] 能看到 15 张变更单
- [ ] 能从变更单跳到需求

## 任务 9：导出交付件

**目标**：产出 Word / Excel / PDF。

**步骤**

1. 打开 `SYS_系统需求规格`。
2. 菜单 `文件 → 导出 >`：
   - `电子表格...` → Excel
   - `富文本格式...` → RTF（Word 可开）
   - `纯文本...` → txt
   - `FrameMaker...` → 专业排版
3. 选 `电子表格...`，指定文件名和路径，确定。
4. 要 PDF：`文件 → 打印...`（Ctrl+P）→ 打印机选 `Microsoft Print to PDF`。

**预期结果**

- 导出内容跟随**当前视图**（列、过滤、级别）。
- 章节层级会体现在导出文件里。

**检查点**

- [ ] Excel 能打开，行数与模块对象数一致
- [ ] Word 里能看到 1 / 1.1 / 1.2 的标题层级

## 任务 10：基线

**目标**：给模块拍快照，用于版本对比。

**步骤**

1. 打开要建基线的模块（如 `SYS_系统需求规格`）。
2. 菜单 `文件 → 基线 >`。
3. 选"新建基线"（不同版本菜单名可能略有差异）。
4. 填写基线名 `v1.0-demo`，可加描述，确定。
5. 查看：同一菜单里选"查看基线"或在模块属性里看基线列表。

**预期结果**

- 基线是只读快照，后续修改不影响已发布基线。
- 基线可用于两个版本对比、差异报告。

**检查点**

- [ ] 基线列表里出现 `v1.0-demo`

> 说明：本项目的自动化链路用"快照文件 + 清单"模拟基线（`output/releases/`），
> 因为 DXL 的基线接口在本环境返回 false；DOORS 原生基线只能在 GUI 里建。

## 核心概念速查

| 概念 | 一句话 |
|---|---|
| 模块（Module） | 一张需求表，每行一个对象 |
| 对象（Object） | 需求或章节标题 |
| 链接模块（Link Module） | 关系的容器，里面按"链接集"分组 |
| 链接集（Linkset） | 一对模块之间的全部链接 |
| 出链 / 入链 | 我指向别人 / 别人指向我 |
| 绝对编号 | DOORS 内部编号（119），用于"转至" |
| 业务编号 | 正文里的编号（SYS-0001），用于"查找" |
| 视图（View） | 列 + 排序 + 过滤的配置 |
| 基线（Baseline） | 只读快照 |
| 讨论（Discussion） | 挂在对象上的评审意见 |

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 行尾没有箭头 | 显示开关关闭 | `查看 → 显示 → 链接箭头` |
| 点箭头不跳转 | 左键只显示路径 | 改用**右键** |
| 列表里看不到链接模块 | 被过滤器隐藏 | 工具栏过滤器勾选"链接模块" |
| `Ctrl+F` 无反应 | 焦点不在表格 | 先点表格区域 |
| 讨论加完找不到 | 不在表格显示 | `讨论 → 查看对象讨论...` |
| 导出缺少列 | 导出跟随当前视图 | 先切回 `Standard view` |
| 模块只读不能改 | 打开方式 | 用"编辑"方式打开（右键模块 → 打开 → 编辑） |
