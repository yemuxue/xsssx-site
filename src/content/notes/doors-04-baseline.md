> 实测环境：DOORS 9.6.1.11，Windows 客户端，Database Manager 账号。  
> 结论先说：**基线集定义 → 基线集（版本） → 模块基线**，三层缺一不可。

## 0. 前提

- 用有 **Database Manager** 权限的账号登录；
- 要打基线的模块已打开，且能进入编辑模式；
- 基线是**模块级**的，所以“文件 → 基线”只在**模块窗口**出现，数据库窗口没有。

## 1. 建“基线集定义”

1. 在数据库树选中模块所在的**文件夹**（例如 `01 系统需求`）；
2. 菜单 **文件 → 属性**（或按 `F2`）；
3. 切到 **“基线集定义”** 标签；
4. 点 **“新建...”**；
5. 输入名称，例如 `v10PPT`，确定。

名称限制：

- 只能用字母、数字；
- `v1.0-PPT` 这类带点号/横杠的名称会报：
  > CRCRD5002E：输入的名称包含一个或多个无效字符。

## 2. 把模块加入基线集定义

1. 在“基线集定义”列表里选中刚建的 `v10PPT`；
2. 点 **“查看/编辑...”**；
3. 在 **“定义”** 标签的左侧树里选中 `SYS_系统需求规格`；
4. 点 **“添加”**，模块出现在右侧“模块名称”列表；
5. 点 **“确定”** 保存。

## 3. 建“基线集”（版本）

1. 回到 `v10PPT` 的属性窗口；
2. 切到 **“基线集”** 标签；
3. 点 **“新建...”**；
4. 输入版本，例如 `1.0`，确定。

此时列表里会出现 `1.0`，“打开”列可能显示 `*`，表示基线集处于打开状态。

## 4. 给模块打第一个基线

1. 打开 `SYS_系统需求规格` 模块窗口；
2. 菜单 **文件 → 基线 → 新建...**；
3. “基线集”下拉里应出现 **`v10PPT [1.0]`**；
4. 选中它，版本选 `1.0`；
5. 点 **确定**；
6. 弹出“您即将添加当前模块到基线集：v10PPT [1.0]，是否继续？” → **确认**。

成功后模块标题会变成：

```text
/01 系统需求 中的“SYS_系统需求规格”当前 1.0（正式 模块）
```

## 5. 改需求，再打第二个基线

1. 在模块里修改若干需求（例如把“3 秒”改成“2 秒”），`Ctrl+S` 保存；
2. 再次 **文件 → 基线 → 新建...**；
3. 选 `v10PPT [1.0]`，版本选 **1.1**，确定并确认；
4. 模块标题变为“当前 1.1”。

> 注意：如果两次基线之间没有改任何内容，比较结果当然为空——基线只是快照。

## 6. 比较两个基线

1. 在模块窗口点 **文件 → 基线 → 比较...**；
2. 左右两个列表各选一个**不同**版本：
   - 左边选 `1.0`
   - 右边选 `1.1`
3. 点 **“比较”**；
4. 打开 **“基线比较结果”** 窗口，按“已修改的对象”列出每条需求的改前/改后两行。

如果两边选同一个版本，会提示：

> 请从每个列表中选择不同版本。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 模块“文件”里没有“基线” | 当前是数据库窗口；先打开具体模块 |
| “基线集”下拉只有 `[None]` | 只建了基线集定义，还没建“基线集”版本，或模块没加入定义 |
| 新建基线报名称无效 | 名称只能字母数字，不要点号、横杠 |
| 比较按钮无结果 | 两边选了同一版本，或两次基线之间没有改动 |
| DXL `baseline(Module)` 返回 `false` | 本环境 DXL 基线接口不可用，原生基线走 GUI |
| 改了链接但比较看不到 | 模块基线只快照模块内容；链接模块需要单独打基线 |

## 一句话流程

> 文件夹属性 → 基线集定义（新建）→ 编辑加模块 → 基线集（新建版本）→ 模块 文件→基线→新建 → 改需求保存 → 再建下一版本 → 文件→基线→比较。
